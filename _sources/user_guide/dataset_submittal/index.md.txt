# Dataset Submittal

Submitting a dataset to a project connects a registered dataset to a specific
dsgrid project. During submission, dsgrid registers dimension mappings, checks
that the dataset dimensions will align with the project's base dimensions, and
validates that the mapped dataset will cover all required dimension combinations.
This section covers the submission process and validation checks. Links are
provided to relevant information covered elsewhere.

For a guided introduction, see
[Getting Started: Dataset Submitters](../../getting_started/dataset_submitters).

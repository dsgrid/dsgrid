# Software Citation

When referencing dsgrid toolkit software in academic work, please cite the foundational
technical report:

::::{tab-set}
:::{tab-item} APA
Hale, E., Horsey, H., Johnson, B., Muratori, M., Wilson, E., Borlaug, B., Christensen, C., Farthing, A., Hettinger, D., Parker, A., Robertson, J., Rossol, M., Stephen, G., Wood, E., & Vairamohan, B. (2018). *The Demand-Side Grid (dsgrid) Model Documentation* (NREL/TP-6A20-71492). National Renewable Energy Laboratory. [https://doi.org/10.2172/1465659](https://doi.org/10.2172/1465659)
:::
:::{tab-item} BibTeX
```bibtex
@techreport{hale2018dsgrid,
  title     = {The Demand-Side Grid (dsgrid) Model Documentation},
  author    = {Hale, Elaine and Horsey, Henry and Johnson, Brandon
               and Muratori, Matteo and Wilson, Eric and Borlaug, Brennan
               and Christensen, Craig and Farthing, Amanda and Hettinger, Dylan

               and Stephen, Gord and Wood, Eric and Vairamohan, Baskar},
  year      = {2018},
  institution = {National Renewable Energy Laboratory},
  number    = {NREL/TP-6A20-71492},
  doi       = {10.2172/1465659}
}
```
:::
::::

A `CITATION.cff` file in the software repository [https://github.com/dsgrid/dsgrid](https://github.com/dsgrid/dsgrid) enables GitHub's "cite this repository" feature. For a list of datasets and associated citations, please see [Published Datasets](published_data/published_datasets.md). Likewise, [Publications](publications.md) provides a full list of dsgrid-related publications.

# Dataset Submittal

Submitting a dataset to a project connects a registered dataset to a specific
dsgrid project. During submission, dsgrid registers dimension mappings, aligns
dataset dimensions with the project's base dimensions, and validates that the
mapped dataset covers all required dimension combinations. This section covers
the submission commands, mapping file formats, and validation checks.

For a guided introduction, see
[Getting Started: Dataset Submitters](../../getting_started/dataset_submitters).
